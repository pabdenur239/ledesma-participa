Estudiantes de Instituto Técnico Fátima de CABA desarrollaron sistema de alerta temprana para prevenir incendios forestales

25 de octubre de 2026, 01:49 hs · Infobae

Estudiantes del Instituto Técnico Fátima de CABA desarrollaron junto con sus profesores un sistema de alerta temprana que busca prevenir incendios forestales mediante sensores que monitorean las condiciones ambientales. El sistema, denominado FireNova, fue finalista en un premio global de sostenibilidad. La iniciativa se realizó en colaboración con el instituto, manteniendo la neutralidad editorial y respetando la información proporcionada.
